# Gaussian Distribution Visualizer

A Python script to generate and visualize Gaussian (normal) distributions.

## Features
- Takes user input for mean and standard deviation
- Generates 1,000,000 random samples from the distribution
- Calculates and displays theoretical and sample statistics
- Plots the probability density function (PDF) with shaded area
- Saves the visualization as a high-quality PNG image

## Requirements
- Python 3.x
- numpy
- matplotlib

## Usage
1. Run the script:
   ```bash
   python gaussian_distribution.ipynb

    Enter the mean value when prompted

    Enter the standard deviation when prompted

    View the generated statistics and plot

    The plot will be saved as gaussian_distribution.png

Output

    Displays mean, input standard deviation, and sample standard deviation

    Generates a plot showing:

        The Gaussian PDF curve

        Shaded area under the curve

        Annotations with standard deviation values
